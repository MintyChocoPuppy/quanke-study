# quanke-study

全科医学学习站点：https://quanke.study.cn.lazynas.com/

- 教材共 306 页，按原书目录分为前置部分、24 章、篇扉页及尾部资料，共 29 个独立阅读单元。
- 普通打开先加载封面、前言和目录（PDF 1–20）；向下滚动到正文或点击目录时才载入对应单元。
- 大多数单元是独立 PDF。前置 PDF 使用自己的清单和传输块按范围重组，校验每块长度与 SHA-256；这些资源不引用正文其他章节。
- 页码、教学大纲与笔记链接均使用整本 PDF 的全局页码；带 `?page=` 的链接优先。普通打开可通过“继续阅读”返回上次位置。
- “下载本章PDF”重组或下载当前单元；“下载原版PDF”与“整本阅读与打印”只在主动点击时使用整本文件。
- 保留 59 篇笔记、教学大纲分类、搜索、侧栏、阅读布局、导出和打印。独立笔记提供返回教材及对应教材入口，并保留当前笔记上下文。

教材拆分逐页核验了 306 页文字与栅格渲染。PDF.js 独立工作线程测试核对了封面及 PDF 21、117 的渲染一致性；请求测试确认首屏无正文章节请求，直达第八章不请求中间章节。本地测试首屏教材数据约 9.95 MB，旧整本范围读取约 92.4 MB；这不是中国大陆实网速度保证。

本站为公开静态阅读站，不连接私人笔记的写入接口。原 ChatGPT/Sites 站点独立保持私密，不随此仓库发布而改变。
